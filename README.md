# 면역학 개론 기출 퀴즈

「면역학 개론 기출문제 정리」(22·23학번 + 역대 모음) PDF를 퀴즈로 만든 정적 사이트(HTML/CSS/JS)입니다. 서버 없이 GitHub Pages에서 바로 동작합니다. 형식은 [22midterm](https://github.com/yeonn10/22midterm)과 같고, 과목은 면역학 개론 하나라서 과목 선택 단계가 없습니다.

- 총 144문항: 객관식 114 · 주관식 30 (1~9단원)
- 1~6단원은 교안 범위, 7~9단원은 `[교안 외]` 문항입니다. 정답은 PDF에 표시된 기준입니다.
- 그림이 있는 문제 7개(1-2, 1-14, 2-6, 3-11, 3-12, 4-5, 7-12)는 `img/` 폴더의 그림이 함께 나옵니다.

## GitHub Pages 배포
1. 이 폴더의 **모든 파일**(`.nojekyll` 포함)을 저장소 루트에 올립니다.
2. Settings → Pages → Branch: `main` / `/ (root)` → Save
3. 잠시 후 `https://<아이디>.github.io/22quiz/` 접속

로컬 확인: `index.html`을 브라우저로 열면 됩니다.

## 문제 유형별 풀이 방식
| 유형 | 방식 |
|---|---|
| 객관식 | 번호를 고르고 확인. 정답이 여러 개면 모두 골라야 정답 (보기가 15개까지 있는 문항도 있음) |
| 주관식 단답 | 영어 단어를 입력. 대소문자·띄어쓰기·하이픈은 무시하고 비교 |
| 주관식 나열형 | 쉼표(,)로 구분해 여러 개 입력 (예: "List five soluble components…"). 필요한 개수 이상 맞히면 정답 |

주관식은 PDF의 지시사항(약자 불허 등)에 맞춰 허용 답안을 넣어 두었지만, 표현이 달라 오답 처리되면 결과 화면의 **내 답도 맞게 인정** 버튼으로 직접 바꿀 수 있습니다. 반대로 **오답으로 처리**도 됩니다.

여러 질문(Q1, Q2…)이 보기를 함께 쓰는 문항은 질문마다 한 문제로 나뉘어 있습니다. 번호는 PDF 번호를 따릅니다 (예: `7-13 Q3`).

## 단축키
| 키 | 동작 |
|---|---|
| 1–9 | 보기 선택 (정답이 여러 개인 문제는 여러 개 선택) |
| 보기 10번 이상 | 숫자를 빠르게 이어서 입력 (1 → 2 = 12번). 한 자리만 누르면 잠깐 기다렸다가 확정 |
| Enter | 선택한 답 확인 → 답이 나온 뒤 Enter는 다음 문제 (주관식은 입력칸에서 Enter) |
| 0 | 모름 (즉시 정답 표시) |
| → / ↓ | 다음 문제 |
| ← / ↑ | 이전 문제 |
| B | 북마크 추가 / 해제 |

주관식 입력칸에 커서가 있을 때는 숫자·방향키가 글자 입력에 쓰입니다.

오답·모름은 "북마크 자동 저장"을 켜면 자동 북마크됩니다. 북마크는 브라우저 localStorage에 저장되며, 북마크 화면에서 txt로 내보내기/불러오기가 가능합니다(문제 고유번호 목록). 22midterm 사이트와 저장 키가 다르므로 서로 섞이지 않습니다.

## 문제 추가·수정
1. `tools/build.py` 안의 문제 목록을 편집합니다. (`mc` 객관식, `grp` 보기를 공유하는 묶음, `short` 단답, `shorts` 빈칸이 여러 개인 단답, `lst` 나열형)
2. `python3 tools/build.py` → `questions.js` 재생성 (id 중복, 정답 번호 범위, 그림 파일 존재 여부 검증 포함)

새 그림은 `img/{문제번호}.jpg` 로 넣고, `mc(..., fig=True)` 또는 `short(..., fig=True)` 로 연결합니다.
